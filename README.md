# سامانه دستیار آمار و مدیریت بالینی دکتر دوانلو

نسخه پیشرفته و بازطراحی‌شده سامانه دستیار آمار، ثبت مشاوره‌های بخش، پروسیجرهای مداخله‌ای، ساسپند تصویربرداری و پیگیری وظایف بالینی دکتر دوانلو.

## ویژگی‌های اصلی
- 📱 طراحی مدرن سازگار با موبایل (PWA) با پشتیبانی کامل از ژست‌های حرکتی (Swipe) و فیدبک لرزشی (Haptic)
- 🏥 مدیریت دو ستونه فشرده بخش‌ها با دکمه‌های دسترسی سریع «بیمار» و «بی‌مورد»
- 🔄 مرتب‌سازی ترتیبی بخش‌ها و یادداشت‌ها با قابلیت Drag & Drop (`@dnd-kit`)
- ☁️ همگام‌سازی ابری امن با GitHub Gist و ذخیره‌سازی آفلاین محلی (Offline-First)
- 📊 گزارش‌گیری پیشرفته روزانه، خلاصه مالی، خروجی اکسل (CSV) و فایل پشتیبان JSON

## اجرا و استقرار
پروژه با React + Vite + Tailwind CSS ساخته شده و از طریق GitHub Actions به‌طور خودکار روی GitHub Pages منتشر می‌شود.
